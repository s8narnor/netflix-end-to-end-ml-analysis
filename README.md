## 📊 Netflix End-to-End ML Analysis

### 🔍 Project Overview
This project focuses on data preprocessing, visualization, and machine learning readiness using the Netflix Movies and TV Shows dataset.
It demonstrates how raw data is transformed into a machine-learning-ready format and how preprocessing impacts model performance.

### 🎯 Objectives
- Perform data understanding and identify data quality issues
- Apply data cleaning and preprocessing techniques
- Visualize key trends and patterns
- Train classification models
- Compare performance before and after preprocessing
- Analyze the role of preprocessing in the ML lifecycle
